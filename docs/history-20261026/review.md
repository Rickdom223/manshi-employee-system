# 初步代码与运行审查

结论：P0功能已经实现并有本机自动化与浏览器证据；CloudStudio平台部署仍需实际空间验收。本报告为开发者初步自查，不是独立安全审计或生产上线认证。

## 已检查

- 六表无越界模块；SQLite外键启用，唯一和枚举/归档日期约束；新增/修改岗位部门关系在后端校验。
- 部门岗位技能停用保留历史；岗位被员工引用后变更部门会409；归档员工不物理删除。
- 工号不可PATCH，空姓名、错误日期、无效关联、分页边界均拒绝；组合筛选与真实数据统计有测试。
- Argon2id哈希；HS256 JWT强制sub/exp、签名、过期及用户启用状态；没有明文密码返回、Cookie或持久化Token。
- 业务路由统一鉴权；登录失败通用信息；基本IP节流；统一中文错误，不返回内部堆栈；关闭匿名调试文档。
- 前端API使用相对/api，两个代理保留前缀；Host校验开启，没有CORS通配；浏览器验证请求均同源。
- 初始化幂等；.env、数据库、备份与依赖目录排除交付；在线备份、恢复副本两次进程重启读取通过。
- npm审计发现初选依赖漏洞后，升级Vue、Axios、Element Plus、Vite、Playwright；复查0项已知漏洞，详情JSON已保存。

## 修复记录

1. 系统未提供npm：在忽略的.tools目录下载npm工具，不改变全局安装；缓存移到项目内，完成依赖锁定。
2. 空CSS import产生构建警告：移除；构建通过。拆分Vue、Element Plus供应商包；Element Plus包仍较大，保留性能提示。
3. 日期选择器弹层同样带dialog角色，浏览器测试定位有歧义：归档按名称定位，其余表单定位可见el-overlay-dialog，避免动画时序造成歧义；产品流程复验通过。
4. Windows中SQLite连接上下文退出只提交事务、不关闭连接，导致验证临时副本清理失败：改为contextlib.closing显式关闭，副本重启及清理通过；备份工具同样修正。
5. Shell预检在精简PATH下dirname不可用：根路径定位改为Bash参数展开，不再依赖dirname。Bash语法与缺少Linux虚拟环境的友好失败分支已实测。
6. 前端升级后的首次浏览器重跑遇到服务正在重启（ECONNREFUSED）：启动Vite6.4.5后重跑，完整通过。

## 已知限制与未验证

- Windows/MSYS只能验证Bash语法和部分预检；CloudStudio Linux完整启动/信号清理、平台HTTPS/HMR、分享权限、外部窗口访问尚未验证，不能宣称已部署成功。
- 基本限流在单进程内，代理IP可能共享，重启清空；没有分布式限流、服务端JWT撤销或安全审计日志。
- 后端依赖进行了版本锁定、pip check和运行测试，未进行独立完整CVE扫描；npm audit为当时数据库结果，不能保证未来无漏洞。
- Element Plus供应商构建包超过500kB，构建有性能提示；课程桌面环境使用可接受，后续可按需导入组件。
- Starlette测试客户端与AnyIO有一条弃用警告。测试通过，不是应用业务失败；后续依赖升级须重新验证。
- 数据库首次建表，无自动schema迁移机制；未来变更字段需独立迁移计划。
- 当前Vite为课程临时预览服务，真实企业生产部署、HTTPS网关加固、撤销机制、审计与灾备不在本次范围。
- Chrome真实浏览器流程已自动化验证；Edge的全部流程及真实手机浏览器未验证。本版仅要求桌面。

验收证据见 checklist.md、docs/test-results.md、docs/e2e-results.json 和截图目录。
