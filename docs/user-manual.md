# 使用手册：多标签工作区版

## 登录

本机打开 http://127.0.0.1:3000/login ，使用 **ljm / Ljm123**。原demo_admin凭证仍可使用。首次部署请在系统设置修改初始密码，新密码8–10位且含大小写字母与数字。普通员工使用管理员开通账号时得到的员工编号与初始密码，不能自行注册。

刷新网页会恢复有效会话，默认8小时；右上角退出会撤销服务端会话。会话失效后需要重新登录，已保存的业务资料不会丢失。

## 顶部多标签导航

点击左侧菜单，在右侧顶部新增或激活对应标签。比如打开“员工信息管理”“薪资管理”“制琴任务管理”，三个标签同时保留，可直接从顶部切换，浏览器地址和左侧高亮同步变化。

重复点同一菜单不会重复开标签。普通标签右侧×可关闭；关非当前标签不跳页，关当前标签优先回左边相邻标签，首页常驻不可关闭。筛选和未提交输入会保留；关闭有修改的标签时显示确认，取消即可继续编辑。弹窗内正在输入时也能切到其他标签，返回仍保留内容。标签太多时横向滚动。

刷新在同一浏览器页签中恢复打开顺序与当前页面。退出、会话过期或切换账号会清掉旧工作区。员工不会继承管理员标签。

## 管理员业务操作

1. **部门与岗位管理**：内部切换“部门管理、岗位管理、制琴技能字典”。先建部门，再为部门新增岗位。可编辑、启停；有员工/历史关联时不能删除。部门行“查看岗位”切到该部门岗位列表。原多技能字典继续保留。
2. **员工信息管理**：点新增员工，填写姓名、手机号、部门、岗位、入职日期、基本工资；可填写性别、出生日期、备注。编号保存时自动生成。勾选同时创建登录账号并设置合规初始密码，即可让员工登录。详情中也可开通账号/重置密码、添加多项技能和调整熟练度。列表支持查询、分页、编辑和Excel导出。
3. **离职处理**：点击归档，填写离职日期并确认。账号随即禁用，历史考勤、工资和任务保留；在离职/全部筛选中可查询。本版没有误操作后直接恢复在职的按钮。
4. **考勤管理**：录入员工、日期、状态，可填上下班时间。相同员工同日不能重复；下班不能早于上班。按月、日期、姓名、部门、状态筛选，查看月度汇总和导出。没有记录不自动算缺勤。审批联动的请假考勤不能直接改。
5. **请假审批**：待审批申请可通过或驳回，驳回填写原因。通过会生成覆盖工作日的请假考勤；已有考勤/批准请假冲突时整笔回滚，不会覆盖记录。重复审批被拒绝。
6. **薪资管理**：选月份生成草稿，重复生成只补缺失记录。编辑未发放工资的奖金/扣款，实发由后端计算，不能为负。标记已发放须确认；再编辑前须确认撤回发放。可筛选和导出Excel。
7. **制琴任务管理**：新增任务填写名称、型号、计划数量、负责人、多人参与、开始和预计完成日期。开始制作→编辑进度→数量达到计划后提交质检。质检不通过退回制作中且保留记录；通过后再点确认完成。已完成任务只读保留，详情可看全部质检历史。
8. **统计报表**：选择部门、考勤、工资或制琴完成量及月份，查询真实数据库聚合并导出。工资“已生成支出”和“已发放支出”分开显示。
9. **系统设置**：维护本人显示名称，输入旧密码、新密码、确认密码进行改密。企业信息固定为满氏吉他制琴有限公司。

## 普通员工

左侧只有六个个人模块，使用同样的顶部标签工作区：个人信息允许修改自己的联系方式；个人考勤只读本人记录及月汇总；请假申请可提交和撤销本人待审批申请；我的工资只读本人数据；我的任务仅显示本人负责/参与任务及质检历史；账号设置可修改本人密码。不能通过修改URL或employee_id读取其他人资料。

## 提示处理

字段校验失败时按提示补全必填项，日期和金额须有效；部门岗位必须匹配。冲突提示通常表示重复记录、已审批、已发放或历史关联，不要反复点击。登录失效后重新登录；连接失败请检查服务是否启动。所有写入保存成功后再切换或退出，标签缓存不替代数据库保存。
