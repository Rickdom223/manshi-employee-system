# 当前系统的短班次打卡演示

用户明确要求：在当前系统配置短班次，挑选几人显示正常、迟到、早退、缺卡和未打卡的效果，不显示测试记录标签。

脚本先备份当前库，保留已有打卡和密码，通过原有HR规则API和员工本人打卡API执行；使用真实服务器时间，不回写或伪造打卡时刻。只临时建立本次操作所需的服务端会话，操作结束后撤销，其他人的登录会话不受影响。

运行命令（会在当前库创建规则和打卡，需明确授权）：

```powershell
& backend/.venv/Scripts/python.exe scripts/run_short_attendance_demo.py --apply-to-current-demo
```
