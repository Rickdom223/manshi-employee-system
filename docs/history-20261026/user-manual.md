# 管理员操作手册

本系统只供管理员维护课程演示资料，所有人员和组织信息均为虚构。

## 登录与退出

打开本机3000地址，或平台实际提供的3000 HTTPS预览地址。在用户名、密码栏输入初始化时设置的凭证。当前本机生成的凭证由你在 backend/.env 私下查看。错误密码和不存在账号统一提示“用户名或密码错误”。连续频繁登录会提示稍后再试。

登录后进入工作看板。顶部显示账号与退出按钮；退出时确认即可。刷新页面、关闭页面或令牌到期后需要重新登录；这是仅内存令牌设计的预期行为。退出只清除当前浏览器内存，不会立即撤销已签发的旧JWT，默认到期时间30分钟。

![登录](screenshots/01-login.png)

## 工作看板

展示员工总数、在职、离职、部门数量和在职员工部门分布。部门数量含停用部门；部门分布含零人的部门。新增/归档后返回看板或点击“刷新统计”，查看数据库最新结果。加载失败可重试，空库显示零值。

![看板](screenshots/02-dashboard.png)

## 员工档案

进入“员工档案”。默认只列在职员工；可以输入姓名或工号关键词，并组合部门、状态、技能筛选，点击“查询”。选择“离职”查归档记录，选择“全部”查所有记录。重置恢复默认在职筛选。列表支持分页，不展示电话与备注。

点击“新增员工”，填写工号、姓名、部门、主要岗位、入职日期。工号2–20位英数字、横线或下划线且全局唯一；姓名不能为空。选择部门后岗位选项联动，变更部门须重新选择匹配岗位。电话和备注可以留空。保存成功后显示新档案。

点击“编辑”更新资料；工号创建后不可修改。历史部门/岗位停用时仍可保留原关联并修正姓名备注；不能新分配到停用部门或岗位。归档员工仍可修正资料，但入职日期不能晚于已有离职日期。

![员工查询](screenshots/04-employees.png)

## 员工详情与技能

点击员工行的“详情”，查看部门、岗位、完整可选电话、备注、在职/离职及离职日期。详情下方可选择未关联且启用的技能，再选择“基础/熟练/精通”并添加。每人可以关联多项技能。

在已关联技能行直接调整熟练度；“解除关联”须确认，只删除这名员工与该技能的关联，技能字典和员工档案仍保留。停用技能仍显示历史关联，可调整既有熟练度，不能给其他员工新分配。关联完成后可在员工列表按该技能筛选。

![员工技能](screenshots/03-employee-skills.png)

## 离职归档

在列表或详情点击“离职归档”，选择不早于入职日期的离职日期，确认归档。归档后状态为离职，档案和技能保留，在职列表不再显示；切换离职筛选仍可查询。本版没有恢复在职或删除员工入口。重复归档会返回冲突提示。

## 部门、岗位与技能字典

左侧分别进入部门管理、岗位管理、制琴技能。点击新增填写编码、名称；岗位必须选所属部门。同一部门岗位名唯一，部门/技能名称全局唯一，编码全局唯一。

点击“编辑”修改字典资料；“停用/启用”需要确认。停用不会删除历史资料，原员工仍显示关联信息，但禁止新的分配。已有员工引用的岗位不能直接换所属部门，请另建新岗位并按需调整员工。部门页面“查看岗位”可直接跳转该部门的岗位筛选。

## 错误处理

- 工号/编码/名称已存在：换一个未使用的值后重试。
- 校验失败：检查提示字段，姓名不能全空格，日期应为有效年月日，部门与岗位必须匹配。
- 找不到员工：返回列表重新查询，或检查地址。
- 登录失效：重新登录，不要在浏览器里修改令牌。
- 服务连接失败：请运行维护者检查两个服务、初始化状态和端口；不要反复提交表单。
- 页面刷新需登录：正常行为，已提交到数据库的员工资料不会因此丢失。
