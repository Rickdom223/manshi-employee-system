# 多标签页版初步审查

本报告为开发者自查，非独立安全认证。本机功能及回归通过；CloudStudio/Nginx现场验收尚未完成。

## 主要变化与兼容

在原代码上增加Alembic迁移、会话、角色权限、考勤/请假/工资/制琴任务/报表；原员工、组织、技能模型与关联保留。旧字段employee_no/full_name/resigned保留物理含义，API额外输出employee_code/name/left以适配新规范。原管理员及密码哈希保留，新增ljm仅首次创建。旧技能页面整合在组织模块内部，原技能API继续鉴权可用。

原库逐表比对验证管理员1、部门6、岗位3、员工7、技能4、技能关联11均保留。迁移前备份仅保存在本机忽略目录；模拟旧库迁移测试可移植到其他机器运行。

## 标签与身份检查

Pinia的tabs store只接受角色菜单白名单，规范化路径唯一；恢复先/api/auth/me确认身份。sessionStorage只存菜单path和activePath，键按用户/角色隔离。每个标签有独立KeepAlive容器；关闭卸载该容器；退出/401清空所有标签和敏感页面。前后路由、侧栏与标签以同一个URL同步。

标签包含dirty接口。关闭有未保存输入的标签会确认；弹窗/抽屉挂在内容区内，能切走并保留状态；关闭后重开销毁旧筛选。角色切换、过期、表单缓存、横向滚动都经过浏览器验证。

## 运行中修复

1. 通用slot放进KeepAlive未正确缓存业务组件，筛选切换后丢失：改为每个标签直接缓存业务组件，UI-TAB-02及关闭后重开通过。
2. 表单输入dirty标记改变可访问名称：标签增加稳定aria-label，保留可见dirty标记。
3. 业务弹窗遮挡顶部标签及切换输入问题：统一WorkspaceDialog/TabPane活动状态，隐藏而非销毁输入，标签关闭释放缓存。
4. 账号切换时Teleport目标尚未插入DOM，触发页面脚本错误：改为onMounted后取得实际HTMLElement再挂载弹窗，完整业务链errors=[]。
5. 前端配置文件BOM导致Vite读取失败：统一改为无BOM UTF-8，TypeScript和构建通过。
6. 浏览器测试遇到隐藏开关输入、日期/时间选择器及旧下拉动画定位冲突：操作可见控件并按aria-controls/命名对话框定位，重跑通过；没有绕过业务API伪造结果。
7. 初选ECharts5.6被npm审计提示漏洞：升级6.1.0、锁定依赖并重跑；审计0项已知漏洞。

## 安全与数据检查

HttpOnly随机会话Cookie、哈希存储、会话撤销、Origin+CSRF、登录节流、Argon2id、角色后端鉴权都有测试。员工范围来自当前会话，不相信请求employee_id。没有公开注册或客户端提权字段。没有向浏览器存储密码、Cookie、CSRF或业务记录。

SQLite外键开启；部门岗位删除检查历史引用；考勤、员工技能、工资、任务成员唯一；请假审批原子写入且冲突回滚；金额整数分，工资快照不追随档案变化；任务数量和质检状态约束由后端执行。Excel导出对公式前缀文本作转义。

## 已知限制

- 限流为单进程按IP/用户名节流，代理IP可能共享；不是分布式防暴力破解。
- 新密码8–10位及公开初始化密码是本SPEC明确要求；首次部署需改密。
- 预置四部门只适用于新库；升级保留用户额外部门，避免删历史。旧档案未填手机号可保留，新建和新修改手机号按11位校验。
- ElementPlus/ECharts包较大，有构建性能提示；没有为消除提示关闭检查。
- 后端测试仍有第三方弃用警告，未进行独立完整CVE扫描。
- Nginx/Linux完整启停、CloudStudioHTTPS预览及分享权限未验证；静态备用模式仅本机HTTP实测。
- 当前没有完整节假日、排班、个税、银行发薪、生产库存等范围外功能。

当前测试与证据见checklist.md和spec-test-results.md；旧报告在history-20261026。
