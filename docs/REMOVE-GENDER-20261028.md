# 移除员工性别属性

按用户要求，员工性别已从数据库模型、创建/修改接口、返回数据、员工详情及保留的旧版表单/列表中移除。Excel模板和导出不包含该字段。携带旧gender字段的新增或修改请求返回422，避免继续收集无用信息。

使用新迁移 `20261028_02` 在原数据库上删除该列，未执行数据重建、员工初始化或密码重置。迁移前自动备份，逐表逐行核对除性别外的所有值完全相同；员工工号、姓名、职级、电话、基本工资、账号密码、权限、主管绑定、离职状态和业务历史均保留。迁移时已有31名员工、32个账号，用户之后新增的员工也完整保留。

实际迁移结果和备份路径见 `remove-gender-results.json`；后端42项测试结果见 `remove-gender-pytest-results.xml`。前端类型检查和生产构建通过，员工详情的浏览器验收加入了无性别字段的检查。

该迁移随正常 `alembic upgrade head` 或启动前初始化执行；不要使用重建脚本应用此修改。当前本机数据库已迁移并重启服务，刷新页面即可看到更新。
